# 云镜 — 安装包发布页

尼康云创（Nikon Imaging Cloud）色彩方案的第三方管理 App（Android）。

> 非官方第三方客户端，与尼康公司无关。仅供学习交流。

## 下载

到右侧 [Releases](../../releases) 页下载最新版 APK：

| 文件 | 适用设备 |
|---|---|
| `app-arm64-v8a-release.apk` | 绝大多数现代手机（推荐） |
| `app-armeabi-v7a-release.apk` | 老旧 32 位机型 |
| `app-x86_64-release.apk` | 安卓模拟器 |

下载后直接安装即可（需允许"安装未知来源应用"）。

## 功能速览

- 滤镜库浏览 / 搜索 / 排序 / 作者筛选与作者页
- 滤镜详情（参数表、样片、EXIF、灵感描述）与 2-4 个并排对比（差异高亮 + 雷达图）
- 多选：保存到「已保存的色彩方案」/ 批量导入相机
- 相机端滤镜拖拽排序、删除；多相机分别管理
- 方案组合（9 槽）一键上机
- 图像传输设置（网盘自动传输开关）
- 滤镜排行榜（点赞/周榜/总榜）

> 相机相关操作需登录尼康账号；滤镜浏览/排行榜无需登录。
